# BRYUM Čištění – nový web

Statický web připravený pro GitHub Pages a doménu `bryumcisteni.cz`.

## Nahrání
1. Rozbalte ZIP.
2. Nahraďte obsah kořenové složky repozitáře soubory z tohoto balíčku.
3. Zachovejte `CNAME` v kořeni repozitáře.
4. Na GitHubu ověřte **Settings → Pages** a zdroj publikování.
5. Po publikaci otestujte `https://bryumcisteni.cz/`, formulář a zobrazení na mobilu.

## Obsah
- `index.html` – hlavní stránka a přehled služeb
- `cisteni-strech.html` – SEO stránka hlavní služby
- `cisteni-okapu.html` – stránka čištění okapů
- `vyskove-prace.html` – stránka výškových prací
- `kontakty.html`, `poptavka.html`, `dekujeme.html`
- `site.css`, `site.js` – společný vzhled a mobilní menu
- `images/logo.webp` – původní logo z dodaného repozitáře, beze změn
- `media/hero-drone.mp4` – aktuální video z dronu
- `robots.txt`, `sitemap.xml` – základ SEO

## SEO
Základ zahrnuje unikátní titulky a popisy stránek, canonical URL, Open Graph, strukturovaná data LocalBusiness/Service/FAQ, sémantické nadpisy, popisy obrázků, robots.txt a sitemap.xml. Po zveřejnění doporučujeme ověřit doménu v Google Search Console a Bing Webmaster Tools a odeslat sitemapu. Samotné SEO nezaručuje konkrétní pozice ve vyhledávání.
